# Padrão de código
- Nomes em ingles, camelCase
- Nomes de variaveis e funçoes sempre devem descrever o que elas fazem.
- Nomes de tipos (interface) devem começar com I.

# Regras Gerais
- Nunca utilize any para tipar variáveis/funções.
- Nunca utilize siglas nos nomes de variáveis/funções, exceto se forem padrões muito conhecidos
